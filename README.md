# FlyUS Airlines - SQL

SQL Server practice project based on a database for an airline.

## What's included?

The database has:

* Passengers
* Airports
* Airplanes
* Flights
* Reservations
* Employees

I also made different queries to practice things like:

* `WHERE`, `LIKE`, `IN`, `BETWEEN`
* `ORDER BY`
* `GROUP BY` and `HAVING`
* `COUNT`, `SUM`, `AVG`, `MIN` and `MAX`
* `CASE`
* `INNER JOIN`, `LEFT JOIN` and `RIGHT JOIN`
* Stored procedures
* Triggers
* `ROLLBACK`

## Technologies

* SQL Server
* T-SQL
* SQL Server Management Studio

## File

The whole project is in:

`FlyUS_Airlines.sql`

This is a practice project I made to improve my SQL and database skills.
